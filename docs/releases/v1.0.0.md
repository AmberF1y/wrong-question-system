## 第一版定位

`v1.0.0` 是面向单用户 Windows 桌面浏览器的本地错题整理与固定规则滚动复习
第一版。它打通以下真实学习闭环：

```text
录入 → 保存 → 调度 → 复习 → 评价 → 再调度
```

## 主要能力

- 树形知识点创建、修改、同树移动和严格删除；
- 错题创建、详情、分页筛选、修改和删除；
- 单题关联一个或多个知识点；
- 单题单张可选图片上传、读取、替换、移除和随题清理；
- PNG、JPEG、WebP、GIF 内容签名校验和 20 MiB 上限；
- 固定规则复习调度、到期队列和四级掌握评价；
- 连续两次熟练后进入已掌握状态，并可手动重新加入；
- 每日复习、按需查看答案、异常恢复和乐观锁并发保护；
- MySQL + Flyway 数据迁移；
- Windows 本地启动、仓库外图片持久化和配套备份流程。

## 运行与数据

默认正式使用路径：

```text
图片：D:\WrongQuestionData\question-images
备份：D:\WrongQuestionBackups
数据库：wrong_question_system
```

启动、停止、备份、清单复核和人工恢复见 `docs/local-usage.md`。

## 已知限制

- 仅支持单用户本地使用，没有用户系统和鉴权；
- 不包含 Dashboard、各科目统计卡片、薄弱知识点聚合和掌握率趋势；
- 不包含 OCR、AI 自动识别、多图片和图片编辑；
- 不展示复习历史，不使用自适应复习算法；
- 没有云端部署、容器化或移动端专项适配；
- 前端生产构建可能提示主 chunk 超过 500 kB，属于后续优化项。
