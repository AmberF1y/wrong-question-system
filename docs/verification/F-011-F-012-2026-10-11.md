## 浏览器流程

使用 Playwright 驱动已安装的 Microsoft Edge，独立无头浏览器上下文；控制
插件初始化因运行资产路径缺失失败，因此这次是自动化浏览器验收，不是用户
人工验收。通过真实 Vite 页面、真实 Spring Boot 后台和数据库执行流程。

- 后端：127.0.0.1:18081，`AI_MODE=demo`。
- 前端：127.0.0.1:5183，开发代理指向独立后端。
- 数据库：本轮新建 `wrong_question_system_ai_acceptance_20261011`。
- 图片：`backend/target/ai-browser-images`；输入为生成的简单数学文字 PNG。

验证步骤和实际结果：

1. 创建数学根节点和「基本运算」子节点；从 UI 选择科目和 PNG，生成任务。
2. 看到排队/完成状态、原图和醒目的演示提示；个人错误答案为空，没有自动保存。
3. 填写题干 `计算 $1+1$ 的值。`、个人错误答案、正确答案、解析和错误原因。
4. 刷新页面后人工编辑仍保留；通过知识树 UI 选择「基本运算」。
5. 用浏览器路由拦截让保存请求实际到达并成功提交，随后丢弃响应。页面锁住编辑
   并提供同步按钮；同步后进入同一道已保存错题，库中总题目数为 1。
6. 检查题图字节与原始 PNG 完全一致、KaTeX 元素显示、复习状态 ACTIVE；首次
   复习日期加一天由集成测试另行断言。
7. 再访问任务详情，显示已保存且无编辑表单。任务中心和全局调用明细均可看到
   演示执行、次数、未知 token 和未知成本；每日额度相对提交前增加一次。
8. 删除任务后列表为空，已保存错题和独立题图仍能读取。
9. 浏览器无未处理 pageerror。检查草稿页和任务中心截图布局。
