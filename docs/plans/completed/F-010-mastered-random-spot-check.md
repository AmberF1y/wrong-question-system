## 目标

在不引入复杂自适应算法的前提下，让已经进入 `MASTERED` 的错题仍能被低频
复核，并在遗忘时重新进入固定规则滚动复习队列。

## 产品规则

1. 普通到期复习优先；当前科目范围仍有到期题时不提供抽查。
2. 每个业务日最多完成 1 道已掌握题抽查，所有科目共用该上限。
3. 候选题必须处于 `MASTERED`，同一道题在最近 30 个业务日内未被抽查。
4. 候选集合不变时，同一日期和科目范围稳定返回同一道题，避免刷新换题。
5. 抽查继续使用不会、模糊、基本掌握、熟练四级评价：
   - 熟练：保持 `MASTERED`；
   - 基本掌握：转为 `ACTIVE`，7 天后复习；
   - 模糊：转为 `ACTIVE`，3 天后复习；
   - 不会：转为 `ACTIVE`，1 天后复习。
6. 每日复习页先消费普通到期队列；队列为空时自动查询当天抽查。

## API

- `GET /api/reviews/mastered/spot-check?subject=数学`：获取当天抽查状态与候选题；
- `POST /api/reviews/{questionId}/spot-check-evaluations?subject=数学`：提交抽查评价；
- 答案仍通过 `GET /api/questions/{id}` 按需加载。

抽查查询只返回题目、科目和图片路径，不提前返回答案字段。

## 数据与并发边界

- `review_record.event_type` 增加 `SPOT_CHECK`，抽查历史与普通评价、手动重新
  加入明确区分；
- 抽查事件的 `scheduled_review_date` 固定为空，因为它不是到期任务；
- V3 迁移增加生成列和唯一索引，保证一个业务日最多写入一个抽查事件；
- `question_review_state.version` 继续提供同题并发乐观锁保护；
- 唯一约束冲突统一返回 `SPOT_CHECK_ALREADY_COMPLETED`，不产生第二条有效历史；
- 不保存题目内容快照，不新增用户、任务或自适应算法表。
