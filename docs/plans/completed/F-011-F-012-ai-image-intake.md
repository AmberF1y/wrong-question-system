# F-011 / F-012 AI 图片辅助录入与任务管理

开始及完成日期：2026-10-11。用户授权直接完成实现和验证，不等待审批。
状态：实现与验证已完成，本次通过 `codex/rag-learning-assistant` 一并提交合并。

## 范围

- 从一张 PNG/JPEG/WebP/GIF 图片提取题干、选项、LaTeX，以及图片中已有的答案/解析。
- 仅推荐现有知识树中的知识点；个人错误答案和错误原因仍由用户填写。
- 可恢复、可编辑的草稿；确认后以同一事务保存错题、题图和任务应用状态。
- 持久化任务、调用记录、有限自动重试、人工重试、取消、每日调用额度、用量及成本估算。
- 模型通过环境变量配置。默认禁用外部调用；显式演示模式清晰标注模拟结果。
- 保留当前复习、抽查、图片管理和不确定评价响应恢复流程。

## 实施和验证

1. Flyway V4 与任务 API、独立模型适配和安全输入存储。
2. 有界后台执行、重启中断恢复、调用日志、幂等确认入库。
3. AI 录入入口、原图/草稿核对、任务列表与详情、可恢复操作。
4. 本地 HTTP 模型夹具、MySQL 集成测试、前端交互测试、类型检查和构建。
5. 补充配置、备份、API、数据库、故障处理与评测说明，记录实际验证结果。

## 边界

不实现 RAG、自动解题、多用户、调度算法改变。当前单实例本地使用；后台执行不宣称分布式高可用。没有真实模型密钥时，不声称识别质量已通过真实模型验收。
