# ADR-002：使用 Flyway 管理数据库迁移并隔离 MySQL 测试库

## 状态

Accepted；已完成 F-005 本地迁移验收。

日期：2026-09-04

## 背景

F-001～F-004 只有三张业务表，结构通过 `sql/init.sql` 手工创建，Hibernate 使用 `ddl-auto: validate` 检查映射。

F-005 需要：

- 新增当前复习状态表；
- 新增复习历史表；
- 增加外键、检查约束和索引；
- 为已有错题回填初始状态；
- 让全新数据库和已有数据库得到同一目标结构；
- 保留可追踪的数据库版本历史。

继续维护一份完整 `init.sql` 无法可靠表达“从旧版本升级到新版本”的过程，也无法记录某个数据库已经执行到哪个版本。

原测试配置还直接连接日常开发库。F-005 增加迁移、级联和并发测试后，继续共用开发库会带来误删或污染真实数据的风险。

## 决策

### 1. Flyway 是唯一业务结构迁移来源

迁移文件位于：

```text
backend/src/main/resources/db/migration
```

- V1 固化 F-004 完成时的三表结构；
- V2 增加复习状态、历史、索引、约束和旧题回填；
- 后续结构修改必须增加 V3、V4 等新迁移。

`sql/create-database.sql` 和 `sql/create-test-database.sql` 只创建空数据库，不再重复维护业务表 DDL。

### 2. Hibernate 继续使用 `ddl-auto: validate`

Flyway 负责改变数据库结构；Hibernate 只核对 Entity 映射是否与迁移后的结构一致。

不使用 `ddl-auto: update`，因为它会在启动时隐式修改结构，绕开版本迁移、代码审查和回滚判断。

### 3. 已有数据库采用一次性显式 baseline

默认配置：

```text
baseline-on-migrate=false
baseline-version=1
```

已有非空开发库在完成备份和结构核对后，首次启动时临时设置：

```text
FLYWAY_BASELINE_ON_MIGRATE=true
```

Flyway 把已有三表结构登记为 V1，再执行 V2。成功后立即移除该环境变量。

默认不开启 baseline，是为了避免把任意错误数据库静默登记为合法基线。

### 4. 集成测试使用独立真实 MySQL 数据库

测试数据源固定为：

```text
wrong_question_system_test
```

选择真实 MySQL，而不是 H2，原因包括：

- V2 使用 MySQL 的 DDL、检查约束和 `DATETIME(6)`；
- 外键级联和索引必须在真实目标数据库验证；
- JPA 乐观锁和两个独立事务需要真实数据库验证；
- H2 的 SQL 方言与并发行为不能替代 MySQL 验收。

测试代码不自动创建或删除数据库。数据库由显式脚本创建，多数集成测试通过事务回滚清理数据，并发测试使用明确 ID 清理。

### 5. 迁移文件执行后不可回写

Flyway 会保存迁移校验和。修改已经执行的 V1、V2 会造成代码与数据库历史不一致，并触发 checksum 校验失败。

因此已执行迁移只读；修正通过新的后续迁移完成。不得为了消除错误而直接执行 Flyway repair，除非已经明确历史记录为什么需要修复。

## 影响

正面影响：

- 空库可以确定性地从 V1 升级到 V2；
- 已有库升级过程可追踪；
- 数据库结构变化进入代码审查；
- Hibernate Entity 漂移能在启动时被发现；
- 自动化测试不再接触日常开发数据；
- 后续 Feature 有明确的数据库版本演进方式。

代价与风险：

- 首次接管已有库需要备份和人工核对；
- 开发者必须理解迁移文件不可随意修改；
- 本地运行测试前必须创建独立测试库；
- MySQL 集成测试比纯内存测试慢；
- 错误 baseline 可能把不兼容结构登记为合法版本，因此默认关闭。

## 未选择的方案

### 继续维护完整 init.sql

不能表达增量升级和数据库当前版本，拒绝。

### Hibernate `ddl-auto: update`

结构变化隐式、不可审查、难以可靠回滚，拒绝。

### H2 测试数据库

无法充分验证目标 MySQL 方言、约束和并发行为，拒绝。

### Testcontainers

能够提供更强隔离，但当前项目已经确认使用本地 MySQL，且不在 F-005 引入 Docker 依赖。后续 CI 需要自包含数据库时再评估。
